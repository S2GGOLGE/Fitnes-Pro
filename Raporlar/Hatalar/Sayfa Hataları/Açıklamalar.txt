# FITNESS PRO – HARİTALAR KONUM İZNİ DÜZELTMESİ

Mevcut Fitness Pro frontend yapısında yalnızca **Haritalar.html içerisindeki "Konum İzni Tekrar İste"** özelliği düzeltilecektir.

## Haritalar.html – Konum İzni Tekrar İste

### Mevcut Sorun

`Haritalar.html` içerisinde bulunan:

**"Konum İzni Tekrar İste"**

butonu düzgün çalışmıyor.

Butona basıldığında mevcut tarayıcı konum izin süreci yeniden başlatılmalı ve kullanıcı konumu alınabiliyorsa harita üzerinde güncellenmelidir.

### Kullanılacak API

Mevcut Browser Geolocation API kullanılmalı:

```javascript
navigator.geolocation
```

Yeni bir konum sistemi oluşturulmayacak.

### Beklenen Davranış

```text
Konum İzni Tekrar İste
        ↓
Tarayıcı konum izni kontrolü
        ↓
Konum alınabiliyorsa
        ↓
Kullanıcının konumu haritada güncellenir
```

### Başarılı Durumda

* Kullanıcının konum marker'ı güncellenmeli.
* Harita kullanıcının mevcut konumuna odaklanabilmeli.
* Konum durumu UI üzerinde güncellenmeli.
* `Konum izni gerekli` mesajı kaldırılmalı.

### İzin Reddedilmişse

Kullanıcı daha önce konum iznini reddetmişse tarayıcı tekrar native izin penceresi göstermeyebilir.

Bu durumda kullanıcıya anlaşılır bir mesaj gösterilmeli:

```text
Konum izni tarayıcı ayarlarından engellenmiş.
Lütfen tarayıcı site ayarlarından konum iznini açın.
```

Kullanıcı izin verdikten sonra **"Konum İzni Tekrar İste"** butonu tekrar kullanılabilmeli.

### İşlem Sırasında

Konum alınırken buton üzerinde veya ilgili UI alanında:

```text
Konum alınıyor...
```

gösterilebilir.

İşlem tamamlandıktan sonra buton tekrar:

```text
Konum İzni Tekrar İste
```

haline dönmeli.

### Hata Durumları

Aşağıdaki durumlar kullanıcıya anlaşılır şekilde gösterilmeli:

* `Permission denied`
* `Position unavailable`
* `Timeout`
* Geolocation API desteklenmiyor

Örnek hata mesajı:

```text
Konum alınamadı.
Lütfen konum izinlerinizi kontrol edip tekrar deneyin.
```

### Backend

**Backend'e kesinlikle dokunulmayacak.**

* Yeni endpoint oluşturulmayacak.
* Mevcut endpointler değiştirilmeyecek.
* Database'e dokunulmayacak.
* Konum backend'e gönderilmeyecek.
* Backend tarafında yeni konum sistemi oluşturulmayacak.

### Kapsam

Bu çalışma **yalnızca `Haritalar.html` içerisindeki "Konum İzni Tekrar İste" özelliğinin düzeltilmesini** kapsar.

Mevcut harita UI ve frontend yapısı korunmalıdır.

Sadece mevcut:

**Browser Geolocation API + mevcut harita UI**

kullanılarak problem çözülmelidir.
